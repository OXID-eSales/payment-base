# Dead-code check — payment-base

**Method.** Read-only. Checkout `payment-base` b-7.4.x, actual HEAD **d062955** (SEAL-1 merge; the 6fc1f0a in the brief is an ancestor, 5 commits behind). I built a reference index of all 525 `src/` classes. Each class was matched by short name and by FQCN, with PHP, YAML and Twig comments stripped, against: payment-base prod (src, metadata.php, views, migration), payment-base `services.yaml`, the 7 consumer repos (stripe, mollie-payment, paypal, one-page-checkout, opalreturns, opalsubscription, oxid-admin-graphql; no vendor/, tests/, docs/, stripe_bkp, .claude), and all tests. I then computed the transitive closure: a class referenced only from dead classes is also dead. I parsed every `services.yaml` service id for consumers, tags and aliases. Events were checked by searching for `new XEvent(` and for handlers whose `getEventClass()` returns them. For public methods, I searched `->m(` / `::m(` / `'m'` across all repos. I also checked metadata settings, the lang keys in templates, menu.xml and oxid-fe-admin, which templates include which, the migrations against the columns read, `@deprecated` and commented-out code. Storefront repos (peroxid, oxid-fe-*) were checked only for GraphQL names. Every pb GraphQL type and controller is live through `NamespaceMapper`.

Verdict key: DEAD = no production reference anywhere; delete it together with its own tests. TEST-ONLY = other tests, often in other repos, use it as a fixture. UNWIRED = registered or extended, but nothing consumes, dispatches or tags it, so it never runs.

Rewrite ContractCreationHandlerTest and update EventListenerProviderTest. ContractFailedEvent must come after batch 1.
