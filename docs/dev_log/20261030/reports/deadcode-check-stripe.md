# Dead-code check — stripe

**Method.** Read-only check of `source/extensions/stripe` @ b4ae8b0 (b-7.4.x); `stripe_bkp` ignored. For each candidate I read its `services.yaml` definition and then followed the wiring by hand: tag → `!tagged_iterator` or the consumer in payment-base, alias → constructor injection, event class → every `new XxxEvent(` dispatch site, webhook handler → `WebhookEventCatalog::EVENTS`. The greps covered stripe, payment-base, one-page-checkout, opalreturns, oxid-admin-graphql-api (src, views, assets, services.yaml, metadata.php), and the whole workspace for MCP/ACP consumers. On top of the candidate list:
- an unused-public-method scan over all non-GraphQL `src/` classes (call sites counted across the same repos);
- metadata settings checked against their readers;
- translation keys checked against all php/twig/js, with prefix-built keys (`STRIPE_VALIDATION_LABEL_*`, `SHOP_MODULE_*`) allowed for;
- every twig include and every `data-controller` traced;
- every esbuild entry and import traced;
- a check of each `services.yaml` FQCN against the files on disk.

Nothing was run (no container, no tests). All line counts come from `wc -l`.
